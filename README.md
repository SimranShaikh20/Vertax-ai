# 📚 Google Gen AI Exchange Program – Vertex AI Learning Journey

Welcome to my learning repository for the **Google Gen AI Exchange Program**, powered by **Google Cloud Skills Boost**. This program equips participants with hands-on experience in **Generative AI**, **Vertex AI**, and building real-world AI applications using Google's cutting-edge ML platform.

---

## 🚀 Program Overview

The **Google Gen AI Exchange Program** is a hackathon and upskilling initiative where participants:
1. Complete curated learning paths on **Google Cloud Skills Boost**
2. Apply their skills in a **real-world AI solution** as part of the final hackathon challenge

---

## 🎯 Learning Objectives

By the end of this program, I will have:
- Gained a strong understanding of **Vertex AI** and its role in building ML/Gen AI solutions
- Learned how to train, deploy, and monitor ML models on Google Cloud
- Built and deployed **Generative AI apps** using **PaLM 2** and **Gemini APIs**
- Completed multiple hands-on labs, courses, and earned skill badges
